# 운영 가이드 — 수업과 학년 운영

## 수업 전

- **차시·과제** 에서 이번 차시의 어휘를 확인하고 «공개» 를 켭니다. 공개한 차시의 어휘만 학생 화면의 «오늘의 과제» 에 나옵니다.
- 필수/선택은 어휘마다 정할 수 있습니다. 필수 과제를 모두 마쳐야 그 차시가 «완료» 로 집계됩니다.
- 학교 어휘의 **뜻풀이는 검토 전 초안**입니다. **어휘·장면** 에서 낱말을 찾아 고치고 «뜻풀이 저장» 을 누르면 «교사 검토 완료» 로 바뀝니다.
- **세 장면의 상황·질문·예시**도 같은 화면에서 고칠 수 있습니다. 예시는 학생이 먼저 자기 글을 쓴 뒤에만 보입니다.
- 국가 사고도구어·수집 어휘는 기본 상황 안내가 나옵니다. 중요한 낱말은 장면을 직접 써 주면 바뀝니다.

## 수업 중

- 학생은 **어휘 → 쓰기 → 수집함** 순서로 움직이면 됩니다. 글은 입력 중에 저절로 저장되고, 저장이 안 되면 «이 기기에 임시로 보관됐어요» 라고 알려 줍니다.
- 학생이 **로그인을 못 하면**: ① 아이디를 확인(교사 화면 «학생» 표) ② 5번 틀리면 10분 잠김 ③ 비밀번호를 잊었으면 «새 코드» → 학생은 «처음 오셨나요?» 에서 새 비밀번호.
- 같은 계정으로 두 기기에서 동시에 쓰다가 충돌하면 학생 화면에 «다른 기기에서 먼저 저장했어요» 와 두 글이 나란히 보여서 고를 수 있습니다.

## 수업 후

- **학생 → 보기 → 문장·피드백** 에서 제출한 글을 읽고 서술형 피드백과 5개 준거(의미 정확성·문맥 적절성·표현 명료성·자기 생각·새 맥락 전이, 1~4점)를 남깁니다. 고쳐서 다시 제출하면 **수정 이력**이 함께 보입니다.
- **현황 → 수집 어휘 검토** 에서 학생이 학급 공유를 요청한 단어를 승인/거절합니다. 승인하면 학급 전체의 수집함 아래에 보입니다.
- **현황 → 학급 통계** 에서 진도가 느린 학생·필수 과제가 남은 학생을 확인합니다.

## 능동 어휘 «판정» 은 이렇게 해요

문장 수만으로 «습득» 으로 보지 않습니다. 한 어휘에서 **이해 → 내 말로 설명(10자 이상) → 문장 쓰기 → 새 맥락 적용**을 모두 했을 때만 «능동» 이 붙습니다. 새 맥락은 «서로 다른 장면에서 2개 이상 제출» 하거나 «복습의 새로운 상황에 쓰기를 맞게 함» 일 때 인정합니다.

## 타이틀 이미지 바꾸기

**자료·백업 → 앱 타이틀 이미지** 에서 파일을 고르면 오른쪽에 미리보기가 나옵니다. «이 이미지로 적용» 을 누르면 모든 학생 화면에 반영되고, «기본 이미지로 되돌리기» 로 처음 이미지로 돌아갑니다.
- PNG·WEBP·JPG, 가로로 긴 이미지(약 3:1)를 권장합니다. 330KB 를 넘으면 자동으로 줄여 올립니다.
- 이미지는 비율만 맞춰 보여 주고 늘이거나 자르지 않습니다. 이미지를 못 불러오면 «힘이 되는 학습도구어» 글자가 대신 보입니다.
- 교사 계정은 서버 관리자만 만들 수 있으므로, 교사만 바꿀 수 있고 학생은 바꿀 수 없습니다.

## 백업과 복구

| 무엇 | 어떻게 |
|---|---|
| 매일 자동 백업 | Apps Script 에서 `installNightlyBackup` 한 번 실행 → 드라이브 `학습도구어_백업` 에 시트 사본이 날짜별로 쌓이고 14개까지 보관 |
| 수동 백업 | 교사 화면 **자료·백업 → 백업 파일 만들기** (우리 학급의 모든 기록 JSON). 이름이 들어 있으니 **안전한 곳**에만 보관 |
| 복원 | **백업 파일로 복원** — 같은 번호의 기록은 덮어쓰고 없는 기록은 되살림. 지우지는 않음 |
| 시트가 망가졌을 때 | 드라이브의 백업 사본을 열어 같은 방식으로 웹 앱을 다시 배포 |

## 학년말 · 개인정보

1. **자료·백업** 에서 진도·문장·수집 어휘를 CSV/XLSX 로 내려받고, 백업 파일도 받아 둡니다.
2. 보관 기간이 지난 학생은 **학생 → 삭제**(아이디를 입력해야 지워짐) 로 계정과 모든 기록을 지웁니다.
3. 다음 학년은 **새 구글 시트 + 새 배포**로 시작하는 것을 권합니다. (표가 커지면 느려집니다)
4. **현황 → 접근 기록** 에서 누가 언제 학생 기록을 열었는지 확인할 수 있습니다.

## 이런 때는

| 증상 | 확인할 것 |
|---|---|
| 화면 위에 «체험 모드» 띠가 있다 | `docs/config.js` 의 `SERVER_URL` 이 비어 있음 → 배포 가이드 3단계 |
| 로그인이 계속 «서버 응답을 읽을 수 없습니다» | Apps Script 배포의 액세스가 «모든 사용자» 인지, 코드를 고친 뒤 «새 버전» 으로 다시 배포했는지 |
| «서버가 바쁘거나…» 가 자주 뜬다 | 한꺼번에 많은 학생이 저장 중. 잠시 뒤 다시. 반별로 시간을 나누면 줄어듭니다 |
| 교사 비밀번호를 잊었다 | Apps Script 에서 `newTeacherCode` 실행 → 로그에 나온 새 초대 코드로 «처음 오셨나요?» |
| 학생이 쓴 글이 사라졌다고 한다 | 교사 화면 «학생 → 보기» 에서 먼저 확인. 없으면 같은 기기의 브라우저에 임시 보관본이 있을 수 있음. 백업에서 복원 |
