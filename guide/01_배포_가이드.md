# 배포 가이드 — 처음부터 따라 하기

> 대상: 코딩을 해 본 적 없는 선생님. 화면이 안내와 다르면 **잘못하신 게 아니에요.** 그 단계의 «문제가 생기면» 을 보세요.
> 처음에는 **체험 모드**(아래 «0단계»)로 앱을 먼저 써 보고, 마음에 들면 1단계부터 진행하세요.

## 한눈에 보기

| 단계 | 하는 일 | 걸리는 시간 |
|---|---|---|
| 0 | 내 컴퓨터에서 체험해 보기 (선택) | 5분 |
| 1 | GitHub 에 올리고 «화면» 주소 만들기 | 15분 |
| 2 | 구글 시트 + Apps Script 로 «저장 서버» 만들기 | 20분 |
| 3 | 화면에 서버 주소 알려 주기 | 5분 |
| 4 | 교사 로그인 → 학급·학생 계정 만들기 | 10분 |

## 0단계. 내 컴퓨터에서 체험하기 (선택)

1. 이 폴더의 **`docs/index.html` 파일을 더블클릭**해 브라우저(크롬 권장)에서 엽니다. 설치할 것이 없습니다.
2. «체험용 계정» 의 버튼으로 선생님·학생으로 들어가 봅니다. 기록은 **이 브라우저에만** 저장돼요. (체험 초기화 버튼이 있습니다)

## 1단계. GitHub 에 올리고 화면 주소 만들기

> ⚠️ **먼저 읽어 주세요 — 공개 저장소 주의**
> 이 폴더의 `docs/data/cards.json` 에는 **국가 사고도구어 카드의 뜻풀이·예문 원문**이 들어 있고, 이용 허락은 아직 확인되지 않았습니다.
> **무료 GitHub 계정은 «공개(Public)» 저장소에서만 GitHub Pages 를 쓸 수 있습니다.** 그러면 카드 본문이 누구에게나 보입니다. 선택지:
> 1. (권장) 국가기초학력지원센터에 이용 범위를 확인한 뒤 공개한다.
> 2. 저장소를 **비공개(Private)** 로 두고, 화면은 Cloudflare Pages·Netlify 같은 무료 서비스에 올린다(비공개 저장소 연결 가능). `docs` 폴더가 «게시 폴더» 입니다.
> 3. `docs/data/cards.json` 을 선생님이 직접 쓴 설명으로 바꿔서 공개한다. (형식은 같은 파일을 보세요)

1. <https://github.com> 에서 새 저장소(New repository)를 만듭니다. 이름 예: `vocab-power-app`.
2. 이 폴더를 올립니다. 터미널에서 (GitHub 아이디와 저장소 이름을 바꿔 넣으세요):
   ```bash
   git remote add origin https://github.com/내아이디/vocab-power-app.git
   git branch -M main
   git push -u origin main
   ```
   처음 푸시할 때 GitHub 로그인 창이 뜹니다.
3. GitHub 저장소 → **Settings → Pages** → «Build and deployment» 의 Source 를 **Deploy from a branch**, Branch 를 **main / `/docs`** 로 고르고 Save.
4. 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다: `https://내아이디.github.io/vocab-power-app/` — **이 주소를 메모**하세요.
5. 주소 뒤에 `data/vocab.json` 을 붙여 열어 봅니다. 글자가 잔뜩 보이면 성공입니다. (2단계에서 씁니다)

문제가 생기면: 주소가 «404» → 3~5분 기다린 뒤 새로고침. 그래도 404 이면 Settings → Pages 에서 `/docs` 를 골랐는지 확인.

## 2단계. 구글 시트 + Apps Script 서버 만들기

> 학교 구글 계정(워크스페이스)은 관리자가 Apps Script 웹앱을 막아 두었을 수 있습니다. 막혀 있으면 정보 담당 선생님께 문의하세요.
> 개인정보가 들어가므로 **학교가 허용하는 계정**으로 진행하는 것이 좋습니다.

1. <https://sheets.new> 로 새 스프레드시트를 만들고 이름을 `학습도구어_데이터` 로 바꿉니다. **이 시트는 다른 사람과 공유하지 마세요.**
2. 위 메뉴에서 **확장 프로그램 → Apps Script** 를 엽니다.
3. 왼쪽 파일 목록의 `Code.gs` 를 열고 **안의 내용을 모두 지운 뒤**, 이 저장소의 [`backend/AppsScript_통합.gs`](../backend/AppsScript_통합.gs) 내용을 **통째로 복사해 붙여 넣습니다.**
4. 코드 위쪽 `CONFIG` 에서 고칩니다.
   ```js
   var CONFIG = {
     SEED_URL: 'https://내아이디.github.io/vocab-power-app/data/vocab.json',   // 1단계에서 메모한 주소 + data/vocab.json
     TEACHER_ID: 'teacher',        // 선생님 로그인 아이디 (바꿔도 됩니다)
     TEACHER_NAME: '선생님',       // 화면에 보일 이름
     ...
   };
   ```
5. 디스크 모양 **저장** 단추. 위쪽 함수 선택 칸에서 **`setup`** 을 고르고 **▶ 실행** 합니다.
   - «권한 필요» 창이 뜨면 **권한 검토 → 내 계정 선택 → 고급 → (프로젝트 이름)(안전하지 않음)으로 이동 → 허용**. (내가 만든 코드라서 나오는 안내입니다)
   - 아래 «실행 로그» 에 `어휘 410개를 시트에 넣었습니다` 와 `교사 계정 «teacher» 초대 코드: XXXX-XXXX` 가 나오면 성공입니다. **초대 코드를 메모**하세요(14일 안에 사용).
   - 시트로 돌아가면 `Users`, `Vocabulary` … 탭이 생겨 있습니다. **직접 고치지 마세요.**
6. 오른쪽 위 **배포 → 새 배포 → 유형 선택(톱니바퀴) → 웹 앱**
   - 설명: `학습도구어 서버`
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**  ← 학생이 구글 계정 없이 쓰려면 꼭 필요합니다
   - **배포** → 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`)을 **복사해 메모**합니다.
7. (권장) 매일 밤 자동 백업: 함수 선택 칸에서 **`installNightlyBackup`** 을 골라 ▶ 실행. 내 드라이브에 `학습도구어_백업` 폴더가 생기고 매일 사본이 쌓입니다.

문제가 생기면
- `setup` 실행 시 `Exception: Request failed … 404` → `SEED_URL` 주소를 브라우저에 직접 붙여 열어 보세요. 글자가 안 보이면 1단계 4~5를 다시.
- 코드를 고친 뒤에는 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포** 를 해야 반영됩니다. (같은 URL 이 유지됩니다)

## 3단계. 화면에 서버 주소 알려 주기

1. 이 저장소의 `docs/config.js` 를 엽니다.
2. 따옴표 안에 2단계 6의 웹 앱 URL 을 붙여 넣습니다.
   ```js
   window.APP_CONFIG = {
     SERVER_URL: "https://script.google.com/macros/s/AKfycb.../exec",
     SCHOOL_LABEL: "2학년 학교자율시간"
   };
   ```
3. 저장하고 GitHub 에 올립니다.
   ```bash
   git add docs/config.js
   git commit -m "서버 주소 연결"
   git push
   ```
4. 1~2분 뒤 화면 주소를 열면 위쪽 «체험 모드» 띠가 **사라져 있어야** 합니다. (띠가 있으면 아직 서버 주소가 연결되지 않은 것입니다)

## 4단계. 교사 로그인과 학급 만들기

1. 화면 주소를 열어 **처음 오셨나요?** 탭 → 아이디 `teacher`, 초대 코드(2단계 5), **새 비밀번호(10자 이상)** → «비밀번호 만들고 시작하기».
2. **학생** 화면에서 «새 학급» → 학년도·학년·반 입력.
3. 학급을 만들면 학생 계정 칸이 나옵니다. 한 줄에 «번호 이름» 으로 붙여 넣고 «계정 만들기».
   ```
   1 학생A
   2 학생B
   ```
4. 뜨는 표에서 **아이디와 초대 코드**를 인쇄하거나 CSV 로 저장해 학생에게 나눠 줍니다. **이 화면을 닫으면 코드를 다시 볼 수 없습니다.** (잃어버리면 «새 코드»)
5. **차시·과제** → «학교 어휘 103개 자동 나누기» → 공개할 차시의 «공개» 에 체크.
6. 학생에게 화면 주소를 알려 줍니다. 학생은 **처음 오셨나요?** 에서 아이디·초대 코드로 비밀번호를 만들고 시작합니다.

## 정상 동작 확인 체크리스트 (꼭 해 보세요)

- [ ] 교사로 로그인 → 학생 한 명으로 로그인(다른 브라우저나 시크릿 창) → 어휘 하나에서 세 장면 문장을 쓰고 제출
- [ ] 교사 화면 «학생 → 보기» 에서 그 문장이 보이고 피드백을 쓸 수 있다
- [ ] 학생 화면에 피드백이 «새 글» 로 보인다
- [ ] 다른 학생 계정으로 들어가면 그 문장이 보이지 않는다
- [ ] 구글 시트 `Writings` 탭에 문장이 저장되어 있다

> 이 가이드의 2단계는 실제 구글 계정에서 직접 해 봐야 확인됩니다. 앱 제작 중에는 구글 서버를 흉내 낸 시험까지만 했습니다([테스트 문서](../design/07_테스트_인수기준.md)).
