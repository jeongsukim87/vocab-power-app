# 1. 요구사항 분석 · 미확정 사항 · 위험

원본: 「힘이 되는 학습도구어」 통합 학습 웹앱 개발 프롬프트(요구사항 명세서).

## 1-1. 목표

학교 필수 학습도구어(원본 104개 항목), 국가 사고도구어(307개), 학생이 직접 찾은 어휘를 한 앱에서 학습하고
**이해 → 표현 → 복습 → 성장 기록**을 서버에 지속 저장한다. 핵심 흐름:

```
어휘 발견 → 문맥 추론 → 의미 이해 → 사고 확장 → 세 장면 작문 → 피드백·수정 → 복습·성찰
```

## 1-2. 사용자와 주요 흐름

| 사용자 | 하는 일 |
|---|---|
| 학생 (PC·태블릿·스마트폰, 구글 계정 없음) | 초대 코드로 비밀번호 만들기 → 로그인 → 학교 어휘/국가 카드 학습 → 세 장면 작문(임시 저장·제출·수정) → 수집함 → 오늘의 문장·복습 → 성장 기록 |
| 교사 | 학급 만들기 → 학생 계정 발급(초대 코드) → 34차시 계획·과제 공개 → 문장 읽고 피드백 → 수집 어휘 승인 → 통계·내보내기·백업 |

## 1-3. 원본 자료 확인 결과 (실제로 읽어 본 값)

| 자료 | 확인한 사실 |
|---|---|
| 학교 어휘 엑셀(가나다순 정리본) | 열: 번호·학습도구어·관련 교과·교과서(출판사)·페이지·뜻풀이(검토용). **고유 표제어 103개**, 교과는 국어·수학·과학·역사·도덕·기가(기술·가정). 「주체」만 쪽수가 둘(49쪽·66쪽)이라 **원본 항목은 104개**로 환산되어 설명서의 104개와 맞는다. 쪽수 «미기재» 는 19개. |
| 국가 사고도구어 PDF | 1,228쪽 = **카드 307장 × 4쪽**(확인·짐작·이해·확장). 글자 크기·색·위치로 요소를 가려내 추출했고, 307장 모두 쪽 이름 순서와 표제어 일치를 검사했다. |
| 학교 ↔ 국가 | 표제어가 똑같은 어휘 **9개**(개요·관점·대안·매체·보편적·원천·주체·초점·추론). 표기·활용형이 비슷한 후보 15쌍. 모두 «후보» 로만 연결하고 자동 병합하지 않는다. |

자세한 대조표: [`data/reports/대조_검증_보고서.md`](../data/reports/대조_검증_보고서.md)

## 1-4. 미확정 사항 (선생님이 정해 주셔야 하는 것)

| # | 미확정 | 지금 앱의 기본값 | 권고 |
|---|---|---|---|
| 1 | **국가 카드 본문(뜻풀이·예문)의 이용 허락** | 선생님 결정으로 본문까지 데이터에 포함. 모든 출처에 `permission_status = UNVERIFIED` 표시 | 저장소를 **비공개(Private)** 로 두거나, 공개 전에 국가기초학력지원센터에 이용 범위를 확인. 불명확하면 `docs/data/cards.json` 을 자체 제작 설명으로 바꾸면 앱은 그대로 동작 |
| 2 | 원본 104개 항목 파일 | 원본 엑셀은 받지 못해 **정리본 설명으로 환산** | 원본 파일이 있으면 `tools/build_data.py` 의 대조 보고서로 한 번 더 확인 |
| 3 | 학교 뜻풀이 | «검토용 초안» 으로 표시. 표준국어대사전과 대조하지 않음 | 교사 화면 «어휘·장면» 에서 고치면 «교사 검토 완료» 로 바뀜 |
| 4 | 학생 개인정보 | 이름·번호·아이디만 저장(교사 입력). 전화·이메일·주민번호 없음 | 학교 기준에 따라 실명 대신 «번호+이니셜» 로 입력해도 앱은 그대로 동작 |
| 5 | 학교 개인정보 운영 기준·교육청 승인 | 확인하지 못함 | 구글 계정/서비스를 쓰는 것이 허용되는지 학교 정보 담당자에게 확인 |
| 6 | 동시 접속 규모 | 학급 1~6개(학생 30~200명)를 가정 | 더 크면 [기술 스택 비교](02_기술스택_비교.md) 의 대안 검토 |
| 7 | 국가 카드의 «사고 기능» 분류 | PDF 에 분류 표시가 없어 **사고 기능 필터는 만들지 못함**(가나다순·검색·관련어 탐색은 가능) | 분류표가 있으면 `vocab.json` 의 `semantic_category` 열에 채워 넣으면 됨 |
| 8 | 동형이의어 판정 | 같은 표제어는 서로 다른 뜻(sense)으로 따로 보존하고 «후보» 로 연결 | 교사가 확인 |
| 9 | 세 장면 상황·예시 | 학교 어휘 103개 × 3장면의 상황·질문·예시를 자체 제작(초안). 국가·개인 어휘는 기본 안내 | 교사 화면에서 고치기 |
| 10 | AI | 사용하지 않음(설명서: 선택 사항) | 필요하면 서버(Apps Script)에서 호출하도록 추가. 학생 글 전송의 적합성은 먼저 검토 |

## 1-5. 위험과 대응

| 위험 | 대응 |
|---|---|
| 공개된 웹앱 주소로 누가 접근 | 모든 요청을 서버에서 토큰·역할·소유권으로 검사. 토큰은 해시로만 저장 |
| 학생이 남의 기록 조회·수정 | 소유권 검사 + 남의 기록은 «없음» 으로 응답. 자동 테스트로 확인 |
| 동시 저장으로 덮어쓰기·유실 | `LockService` 로 쓰기 직렬화 + `rev` 충돌 검사 + `req_id` 중복 방지 |
| 학생 비밀번호 유출·분실 | 초대 코드(1회용, 14일) · 교사 «새 코드» 로 복구 · 5회 실패 10분 잠금 |
| 기기 변경 시 기록 소실 | 서버(구글 시트)에 영속 저장, 새 기기에서 로그인하면 복구 |
| 구글 할당량·속도 | 한 번에 내 기록을 묶어 받는 `sync` 로 요청 수를 줄임. 규모가 크면 대안 검토 |
| 국가 자료 저작권 | 미확정 사항 1 |
| 학생 글이 사라질까 걱정 | 입력 중 자동 저장 + 이 기기에도 임시 보관 + 저장 실패 안내 |
