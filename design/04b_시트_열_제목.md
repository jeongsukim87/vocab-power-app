# 시트(표) 열 제목

> 이 문서는 `tools/gen_docs.py` 가 `backend/Core.gs` 에서 자동으로 만듭니다. 직접 고치지 마세요.

> `:n` 은 숫자 열, `:j` 는 JSON 글자가 들어가는 열입니다. 첫 열이 기본키입니다. 구글 시트의 시트(탭) 이름이 표 이름과 같습니다.
