# 힘이 되는 학습도구어

> **아는 어휘에서 쓰는 어휘로!**
> 어휘를 이해하고, 생각을 확장하고, 나의 언어로 표현하다.

중학교 2학년 학교자율시간 «힘이 되는 학습도구어» 를 위한 **학생용·교사용 반응형 웹앱**입니다.
학교 필수 학습도구어 103개(원본 104개 항목), 국가 사고도구어 307개, 학생이 직접 찾은 어휘를 한곳에서 학습하고,
**세 장면 작문(교과·일상·세상) → 피드백·수정 → 복습 → 성장 기록**을 서버에 지속 저장합니다.

- 학생은 **구글 계정이 없어도** 쓸 수 있습니다(교사가 발급한 아이디 + 초대 코드로 비밀번호를 만듦).
- 기기를 바꿔도 로그인하면 내 기록이 그대로 있습니다.
- 화면은 **GitHub Pages**(정적 파일), 저장은 선생님 구글 계정의 **Apps Script + 구글 시트**입니다. 설치 비용이 없습니다.
- 외부 AI 서비스로 학생 글을 보내지 않습니다.

## 지금 바로 체험하기

**`docs/index.html` 파일을 더블클릭**하면 브라우저(크롬 권장)에서 바로 열립니다. 서버도, 설치도 필요 없습니다.
«체험용 계정» 버튼으로 선생님·학생으로 들어가 보세요. (기록은 이 브라우저에만 저장됩니다)

> 서버 주소가 연결된 뒤에도 주소 끝에 `?demo=1` 을 붙이면(`index.html?demo=1`) 실제 학생 기록을 건드리지 않고 체험 모드로 볼 수 있습니다.
>
> 자동 테스트(`tests/*.html`)는 더블클릭으로는 안 열리고 `python tools/dev_server.py` 가 필요합니다.

1. **[배포 가이드](guide/01_배포_가이드.md)** 를 따라 GitHub 에 올리고 구글 시트 서버를 만듭니다. (약 1시간, 코딩 필요 없음)

> 무료 GitHub 계정은 공개 저장소에서만 Pages 를 쓸 수 있습니다. [배포 가이드 1단계의 안내](guide/01_배포_가이드.md)를 먼저 읽어 주세요.

### 구조 한 줄 요약

```
backend/Core.gs   인증·권한·저장 규칙 (저장소와 무관한 순수 JS)   ─┬─ Apps Script (구글 시트 저장소, Store.gs)
                                                                 └─ 체험 모드·테스트 (메모리 저장소)  ← tools/sync_core.py 로 docs/js/core.js 에 복사
docs/             정적 화면 (GitHub Pages)  — vocab.json · cards.json 은 tools/build_data.py 가 원본에서 만듦
```

### 자주 쓰는 명령

```bash
python tools/dev_server.py          # 내 컴퓨터에서 미리 보기
python tools/sync_core.py           # backend/Core.gs, Sha256.gs 를 docs/js 로 복사
python tools/bundle_gas.py          # Apps Script 붙여넣기용 통합 파일 만들기
python tools/gen_docs.py            # 시트 열 제목·API 문서를 코드에서 다시 만들기
python tools/make_data_js.py        # docs/data/*.json → *.js (더블클릭으로 열리게 하는 데이터 파일)
python tests/check_repo.py          # 데이터 개수·복사본·개인정보 흔적 점검
# 자동 테스트: dev_server 를 켠 뒤 브라우저에서 /tests/run_tests.html 과 /tests/run_gas_tests.html 열기
```

원본(엑셀·PDF)에서 데이터를 다시 만들 때(PyMuPDF·openpyxl 필요):

```bash
python tools/extract_national.py "<국가 카드 PDF 경로>"
python tools/build_data.py "<학교 어휘 엑셀 경로>"
```

## 라이선스·주의

- 코드는 학교 수업에서 자유롭게 고쳐 쓸 수 있습니다.
- 학교 어휘 뜻풀이·작문 상황·예시는 **초안**입니다. 수업에 쓰기 전에 검토해 주세요.
- 학생 정보(명단·내려받은 파일·백업)는 이 저장소에 올리지 않습니다(`.gitignore` 와 `tests/check_repo.py` 가 막습니다).
